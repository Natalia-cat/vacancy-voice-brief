# Голосовой бриф вакансии

Тестовое задание UX/UI Frontend. Заказчик отвечает голосом на четыре вопроса — система проверяет полноту ответов, задаёт одно уточнение, если чего-то не хватает, и собирает готовое описание вакансии. Прогресс — кольцо в духе Face ID, которое заполняется не по числу ответов, а по их полноте.

**Прототип:** https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/ · голос — в Chrome или Edge, в остальных браузерах тот же путь проходится текстом.

## Как посмотреть за минуту

1. Откройте прототип и нажмите **«Посмотреть демо»** — весь путь пройдёт сам за ~25 секунд, включая уточнение и пропуск.
2. Нажмите **«Начать»** и ответьте сами — голосом или кнопкой «Ответить текстом».
3. Состояния ошибок: `?fail=check` (проверка недоступна — интерфейс не показывает ошибку, кольцо заполняется по минимуму) и `?fail=generate` (экран «Не получилось собрать вакансию»).
4. Обновите страницу посреди брифа — предложит продолжить с того же вопроса.

## Запуск локально

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # тесты правил проверки и генерации
npm run build
```
